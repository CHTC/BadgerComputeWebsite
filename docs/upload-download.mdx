# Upload and download files
This guide shows you how to upload and download files in BadgerCompute.

## Prerequisites

- Access to BadgerCompute
- Location of the files on your computer

## Upload files

1. [Launch BadgerCompute](https://launch.badgercompute.wisc.edu) and sign in with your NetID. Choose your preferred environment and click "Start".
1. After the notebook loads, you should see the an interface like the one pictured below.
   <p align="center"><img src="/docs/upload-download/launcher.png" alt="The BadgerCompute interface." style={{height: 'auto', width: '700px'}} /></p>
1. (Optional) Navigate to the directory where you want to upload your file by double-clicking the name of the directory.
    <Alert severity="info" sx={{ my: 2 }}>
    The `work` directory is the only persistent storage across BadgerCompute instances. Any files outside of the `work` directory will be deleted after the session ends.
    </Alert>
1. Click the "Upload" button.
    <p align="center"><img src="/docs/upload-download/upload.png" alt="The upload button." style={{height: 'auto', width: 'auto'}} /></p>
1. Use the dialog box that appears to select your file(s) that you would like to upload. Click "Open" to upload your files.
    <p align="center"><img src="/docs/upload-download/dialogbox.png" alt="The file upload dialog box." style={{height: 'auto', width: '700px'}} /></p>
1. Once your files are uploaded, you should now see them in the navigation sidebar!

## Download files

There are multiple ways to download a file.

**Option 1:** Right-click the file you'd like to download. Select "Download" from the context menu.
    <p align="center"><img src="/docs/upload-download/rt-click-dl.png" alt="The context menu for a file with the download buttton highlighted." style={{height: '500px', width: 'auto'}} /></p>
**Option 2:** When the file is open, go to the top menu bar and click "File" and select "Download".
    <p align="center"><img src="/docs/upload-download/menu-dl.png" alt="The File menu with the download buttton highlighted." style={{height: 'auto', width: '700px'}} /></p>
